# 全国大学生职业规划大赛全流程实战指南 (Career Planning Contest Guide)

本技能提炼自教育部主办的全国大学生职业规划大赛（A类赛事）特等奖/金奖冲奖工程实践，覆盖“通知解读 → 问辩定位 → 履历包装 → 图表生成 → 4页物理排版 → 平台一键填报 → 第二课堂学分闭环 → 答辩路演PPT设计”的完整 SOP。

---

## 核心阶段流水线 (Workflow Pipeline)

```
[阶段1: 多源事实穿透] ──> [阶段2: 防穿帮履历包装] ──> [阶段3: 5大标准图表生成]
                                                              │
[阶段6: 答辩PPT储备]  <── [阶段5: 平台直通与学分闭环] <── [阶段4: 4页确定性PDF排版]
```

### 阶段 1：多源信息透视与事实对质 (Triage & Fact Verification)
收集群通知、官方微信推文方案及平台操作手册，严格进行三源比对：
1. **文件门槛陷阱**：网页表单提示“小于50MB”仅为系统容限，大赛官方方案严格规定：**PDF 格式、文件大小 <= 10MB、正文 <= 2000 字、图表 <= 5 张**，必须以方案红头标准为唯一依据；
2. **指导教师锁死机制（重大红线）**：初赛报名若未填指导教师，后续晋级省赛/国赛时系统将**彻底锁死修改权限**，无法补填！冲奖选手初始报名必须填入指导老师姓名与手机号；
3. **责任主体隔离**：“一式五份纸质版拉杆文件夹”仅限学院最终推荐进校赛的代表选手（成长赛道通常仅2人），普通大二学生（完成第二课堂学分者）**100% 仅需线上填报与生涯闯关，严禁盲目打印**；
4. **活动内容锁定**：成长赛道在平台无“职业测评”功能（该功能仅向就业赛道开放），通知中的“完成相应活动内容”唯一对应平台左侧的 **【生涯闯关】** 答题评级；
5. **双轨时间门禁**：区分“学生端网上截止线（如11月12日24:00）”与“班级/年级收缴死线（通常提前1-2天）”。

> 详见参考字典：[平台避坑与死锁防范清单](./references/platform_traps_checklist.md)

### 阶段 2：画像定位与“无可考证”硬核履历包装 (Persona & Anti-Crosscheck)
根据教育部成长赛道 100 分评审标准（职业目标 25分、学习实践行动 50分、动态优化改进 25分）进行叙事构建：
1. **立意站位**：将个人志向与**国家重大战略（新质生产力、自主可控）**及**高校所在区域的核心优势产业链**（如天津滨海信创谷、深圳智能终端、武汉光谷等）深度绑定；
2. **防穿帮与无可考证法则（核心铁律）**：
   - **严禁虚构**公开可查的权威赛事具体获奖名次（如“蓝桥杯省二”、“数学建模校赛优选奖”、“天梯赛梯队”、“某某国家奖学金”等），此类信息极易被评委在官方数据库或公示名单中一键倒查打假；
   - **必须重度包装“无可外部考证、但极具自驱力与工程说服力”的真实实绩**：
     - *核心课业与数理筑基*：专业基础课扎实优良，多次获得学院优秀课程实训评定；
     - *自主研习与代码实战*：精读开源前沿模型源码，专业算法社区刷题与调试累计代码量超 3 万行，沉淀万字技术笔记；
     - *课题助研与工程实操*：进驻学院专业课题组担任学生科研助理，协助导师攻关算法仿真、测试集构建与数据清洗，在 Linux 下打通模型转换与推理加速验证；
3. **测评工具权威溯源**：注明采用“高校职业规划测评系统”及“北森霍兰德职业兴趣测验（SDS）与 MBTI 性格量表”，切勿编造“在职规赛平台测出霍兰德”。

> 详见话术与案例：[防穿帮与无可考证履历包装高分指南](./references/anti_crosscheck_guide.md)  
> 详见评分映射：[100分专家评审标准穿透映射表](./references/rubric_100_points.md)

### 阶段 3：5 大标准高质感信息图表生成 (5-Chart Suite)
严格对应评审要点，调用 Matplotlib 自动编译 5 张高分辨率（300 DPI）矢量质感图表，杜绝重叠与概念硬伤：
- **图 1：霍兰德代码(IRC)与个人综合胜任力雷达图**（极坐标正圆无变形，图例置于正下方，无任何文字压覆）；
- **图 2：目标岗位胜任力 GAP 差距量化图**（X 轴扩容至 118，图例置顶居中，彻底释放底层数据条与 GAP 标签）；
- **图 3：大学四年“阶梯赋能”实践成长路线图**（节点成果与全文统一为攻读硕士，严禁出现直博矛盾）；
- **图 4：端侧落地技术瓶颈与动态优化攻坚闭环图**（技术方案杜绝硬件幻觉，如 RK3588 必须写真实的 INT8 PTQ/QAT 混合精度量化，严禁写不支持的 FP4）；
- **图 5：生涯 PDCA 闭环演进与大四秋招熔断双轨预案树**（采用 `FancyArrowPatch` 绘制顺时针弧形闭环箭头；预案树设立大四 9 月推免分流与秋招 SP Offer 托底熔断防线）。

> 运行生成脚本：`python scripts/generate_standard_charts.py`

### 阶段 4：字数双口径风控与 4 页确定性排版 (Formatting & Gatekeeping)
采用 ReportLab 进行物理级页面控制，彻底根除跨页割裂与版面断层：
1. **字数双口径绝对风控**：
   - 官方“2000字”在系统分词中英文单词和数字均占词数（如 `260ms`、`8GB`、`32ms`、`99.6%` 均为独立词元）；
   - **黄金字数区间**：纯正文汉字控制在 **1850 - 1880 字**，Word 分词总数锁定在 **1910 - 1940 词**，严守 <= 2000 词硬门禁，留足 60-90 词安全冗余。
2. **大字号与视觉美学**：
   - 杜绝 8-9pt 视力伤害字体；正文字号设为 **10.0 - 10.2pt（行距 15.0pt）**，大标题 15.5pt，表格字号 8.5pt；
   - 页面边距设为 45pt（约 15.8mm），可打印区域充盈饱满。
3. **确定性 4 页物理分页力学**：
   - **Page 1**：标题 + 6项元数据表 + 第一章职业目标全文 + 图1（保持 1.185 比例）。第一章同页完美收口；
   - **Page 2**：第二章标题 + (一)GAP分析 + 图2 + (二)阶段成效与成果转化矩阵表；
   - **Page 3**：(三)四年路线图 + 图3 + (四)高水平育人平台与产业生态协同矩阵表（填充留白）；
   - **Page 4**：第三章优化改进标题 + (一)瓶颈反思与量化闭环 + 图4 + (二)PDCA与大四秋招熔断双轨树 + 图5 + 结语。
   - 每页严格以 `PageBreak()` 收尾，字符均匀分布在 850～950 字符，零孤行、零跨页脱节！

> 编译排版脚本：`python scripts/build_perfect_4page_pdf.py`

### 阶段 5：平台填报直通车与第二课堂认定闭环
为用户输出配套辅助文档，保障 2 分钟极速填报与零失误交差：
1. **《平台填报信息一览表.md》**：
   - 提供标准目标职业名称（含人社部《中华人民共和国职业分类大典》正式编码，如 `2-02-10-11`）；
   - 预设 200 字个人简介文案，各字段一键复制。
2. **《第二课堂认证与生涯闯关指引.md》**：
   - 提供生涯闯关题库速通高分技巧（SMART原则、职业冰山模型、霍兰德RIASEC定义）；
   - 规范个人截图命名（`专业班级-学号-姓名.jpg`）与班级打包规范，对接班长与年级负责人总台账。

### 阶段 6：答辩路演 PPT 蓝图储备
为进军校赛/市赛的优秀选手提前构建 12 页全流程 PPTX 蓝图与 5 分钟演讲口播稿：
- 结构：“初心立志（定方向）→ 躬行笃实（打底座）→ 动态纠偏（破瓶颈）→ 聚力同行（绘未来）”；
- 预置 3 大评委高频攻防 Q&A（针对代码量真实性、硬件底层异构编译难点、考研失利抗风险托底）；
- 当用户需要 PPT 时，直接衔接 `ppt-master` 技能，一键编译出高颜值商业级路演幻灯片。
