# 全国大学生职业规划大赛 100 分评审标准穿透映射字典

教育部《第四届全国大学生职业规划大赛成长赛道方案》官方 100 分制打分细则与得分点映射：

| 评审模块 | 分值 | 官方核心考察要点 | 高分攻坚要领与避坑话术 |
| :--- | :---: | :--- | :--- |
| **一、职业目标** | **25分** | 1. 个人理想与国家需要、经济社会发展紧密结合；<br>2. 结合学科专业与行业发展趋势、就业市场需求分析；<br>3. 综合分析个人价值追求、能力优势、兴趣偏好，目标明确客观。 | **得分要点**：<br>• 绑定国家战略（新质生产力、信创自主可控、高端装备、数字中国等）；<br>• 结合高校区位产业链优势（如天津滨海信创谷、深圳电子信息、合肥新能源等）；<br>• 规范采用权威量表（北森 SDS 霍兰德量表代码 IRC + MBTI INTJ）；<br>• 对标国家职业分类大典标准职业编码（如 `2-02-10-11` 人工智能工程技术人员）。 |
| **二、学习实践行动** | **50分** | 1. 基于目标职业能力要求，科学量化分析 GAP 差距，制定合理可行计划；<br>2. 结合学校育人特色与所学专业，充分挖掘利用学校与社会各种资源；<br>3. 行动中克服困难、灵活应变，取得扎实的阶段性实践成果。 | **得分要点**：<br>• **胜任力 GAP 模型**：量化识别核心技术短板（如模型轻量化 -20分、异构板卡适配 -22分）；<br>• **防穿帮自驱成果**：避开具体不可靠外部竞赛名次，重在专业课优良基础、代码刷题量超3万行、开源源码精读、课题组学生助研实操；<br>• **学校育人平台**：搬出省部级重点实验室、产学研联合基地、双师型导师指导；<br>• **四年一贯制路线图**：大一筑基、大二攻坚、大三融通、大四冲顶，学历与就业口径统一。 |
| **三、动态优化改进** | **25分** | 1. 及时对行动成效进行自我反思与评估，总结分析收获、不足与根本原因；<br>2. 在成长过程中对目标与路径进行动态优化，积极应对环境变化与挑战。 | **得分要点**：<br>• **真实技术阵痛**：还原真实研发挫折（如大模型直接上边缘板卡出现显存溢出与 260ms 高延迟）；<br>• **优化闭环验证**：知识蒸馏 + INT8 PTQ/QAT 量化 + 算子融合，达成显存降 72%、延迟压缩至 32ms、召回率 99.6%；<br>• **PDCA 动态演进**：以季度/学期为周期滚动复盘；<br>• **大四秋招时间熔断预案**：9月推免保研分流点；若推免未达预期，9-10月秋招锁定信创龙头 SP Offer 托底防线。 |
| **门槛资格红线** | **一票否决** | 1. 参赛形式合规；<br>2. 文件大小与字数限制；<br>3. 赛道身份认证。 | **硬性门禁**：<br>• PDF 格式，文件大小严格 <= 10MB（系统虽容限50MB但红头硬性规定10MB）；<br>• 正文纯汉字 1850-1880 字，Word 总词数 <= 1940 词，严守 2000 词天花板；<br>• 图表数量严格 <= 5 张；<br>• 本科低年级全员“成长赛道·高教组”；初赛必须填入指导教师（防省赛锁死）。 |
