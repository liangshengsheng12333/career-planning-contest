# 全国大学生职业规划大赛平台（zgs.chsi.com.cn）避坑与死锁防范清单

本清单系统归纳学信网全国职规赛官方系统的底层交互逻辑与常见操作陷阱，保障全流程零失误。

---

## 一、 系统技术门槛与红头方案规范对质

| 考核项 | 网页表单提示显示 | 官方方案红头文件硬性规定 | 权威判定结论（执行依据） |
| :--- | :--- | :--- | :--- |
| **上传文件体积** | “仅支持pdf格式，文件小于50M” | “PDF格式，不超过10MB” | **必须遵循 <= 10MB！** 50MB为平台底层网络容限，超10MB文件在评审导出或晋级时将被判违规。 |
| **正文字数上限** | 网页未设严格前端字符截断 | “文字不超过2000字” | **严格控制在 1850-1880 汉字（Word词数 <= 1940）**，预留数值与英文词元空间，防止后台机审超限淘汰。 |
| **图表数量限制** | 网页上传PDF不自动统计图片 | “图表不超过5张” | **全案严格锁定为 5 张**，按图1至图5标准编号并在正文中对应呼应。 |

## 二、 关键操作死锁与误区防范（五大避坑红线）

### 1. 指导教师留空死锁陷阱（不可逆机制）
- **现象**：初赛报名页面中，“指导教师”字段未标红星 `*`，支持留空直接点击提交；
- **平台死锁规则**：系统操作手册明确标注：**“若您在参赛报名时未填写指导教师信息，在后续调整省赛/国赛信息页面无法补填其信息！”**
- **防范建议**：任何有志于冲击校赛、省赛奖项的同学，初赛报名时**必须填入至少1位指导教师（姓名、真实手机号、所在高校）**！避免获奖后无法申报“优秀指导教师奖”。若无固定导师，可咨询辅导员或任课老师姓名。

### 2. 赛道与组别错选风险
- **赛道划分**：
  - **成长赛道**：面向普通高校非毕业年级本科生（专科一二年级、本科一二三年级）；
  - **就业赛道**：面向高年级毕业年级本科生及研究生（本科三四年级、硕士博士毕业班）；
- **组别划分**：普通本科高校学生必须勾选 **高教组**，切勿误勾“职教组”！若选错，学院管理员后台将无法归类审核，直接影响第二课堂学分。

### 3. “纸质材料一式五份拉杆文件夹”辟谣
- 官方推文中常出现“所有学生纸质材料一式五份交至活动中心”的通知文字；
- **真实责任归属**：该要求**仅针对学院完成院级初审后、推荐晋级校级现场总决赛的代表选手（成长赛道通常仅2人）**！
- 普通同学（以通过大二第二课堂必修学分为目标）**100% 只需要在系统完成线上报名、材料上传及生涯闯关**，无需打印任何纸质材料。

### 4. “完成活动内容”唯一定义
- 成长赛道在系统左侧侧边栏**无“职业测评”功能**（职业测评专属于就业赛道面向企业求职的选手）；
- 成长赛道对应的“活动内容”唯一指向系统左侧导航栏的 **【生涯闯关】** 模块；
- 学生必须点击【去闯关】，完成规划题目答题并点亮评级星级，方可达成第二课堂双重认定标准。

### 5. 第二课堂规范截图交差双重凭证
各班班长汇总给年级负责人时，应提醒同学提供合格截图：
1. **主截图（报名成功页）**：清晰显示右上角本人姓名、学号、学校、院系；显示“成长赛道 高教组”；显示“报名成功”或“校赛待审核”状态标签；显示上传的 PDF 文件名；
2. **辅截图（生涯闯关页）**：截取已通关点亮星级页面；
3. **命名规范**：`专业班级-学号-姓名-职规赛截图.jpg`。
